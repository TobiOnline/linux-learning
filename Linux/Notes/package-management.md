# Package Management

## Objective

Learn how Ubuntu manages software packages using APT and DPKG.

## Commands Practised

- sudo apt update
- apt list --upgradable
- apt search
- apt show
- sudo apt install
- sudo apt remove
- apt remove --simulate
- dpkg -s
- command -v

## Key Lessons

- apt update refreshes package information.
- apt upgrade installs available upgrades.
- apt install installs software and dependencies.
- apt remove removes a package but may retain configuration.
- apt purge removes the package and its configuration.
- apt autoremove removes unused dependencies.
- A simulated operation previews changes without applying them.
